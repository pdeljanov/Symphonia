# Symphonia TTA Bundle

This crate contains Project Symphonia's native True Audio (TTA) demuxer and decoder for TTA1 streams (simple, unencrypted).

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
