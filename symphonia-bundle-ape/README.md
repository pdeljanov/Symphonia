# Symphonia APE Bundle

This crate contains Project Symphonia's Monkey's Audio (APE) demuxer and decoder. The entropy decoding and prediction stages are provided by the pure Rust [`ape-decoder`](https://crates.io/crates/ape-decoder) crate.

> [!NOTE]
> This crate is part of Symphonia. Please use the [`symphonia`](https://crates.io/crates/symphonia) crate instead of this one directly.
